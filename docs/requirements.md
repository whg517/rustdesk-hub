# RustDesk Hub 首版需求

首版面向使用一个自建 RustDesk Server OSS 实例的个人用户。用户在 Mac 和 Windows 的原生 RustDesk 客户端登录同一个账号后，可以在任一端添加和编辑常用设备，并从同步后的个人通讯录发起远控。

RustDesk Hub 提供账号、会话和通讯录服务。RustDesk Server OSS 提供设备注册、连接协商和中继。被控设备按其 RustDesk 设置完成手动确认或设备密码校验。

## 接入流程

1. 部署时创建一个自用账号。用该账号登录网页管理端，可以查看并复制 RustDesk Hub 的 HTTPS API 地址。
2. 在两台客户端分别进入「设置 → 网络」，填写管理端提供的 API 服务器地址。设备连接使用自建 OSS 实例的 ID 服务器、中继服务器和公钥。
3. 在客户端的「账号」页面使用该账号登录，打开「个人通讯录」。首次接入时可以按设备 ID 添加常用机器。 [RustDesk 客户端配置](https://rustdesk.com/docs/en/self-host/client-configuration/)

## 账号与会话

- 网页和原生客户端使用同一个账号。每次登录建立独立会话，Mac、Windows 和网页可以同时访问同一份个人通讯录。
- 客户端可以恢复仍有效的登录会话。从某一端退出时撤销该会话。
- 网页管理端支持修改账号密码。改密后旧会话失效，各端用新密码重新登录。
- 读取和写入通讯录均要求有效会话，操作范围为该账号的个人通讯录。密码以安全哈希保存。

## 个人通讯录

网页管理端和原生客户端都可以添加条目、编辑别名、标签和备注，以及移除条目。管理端支持按设备 ID 或别名查找条目。

| 字段 | 规则 |
| --- | --- |
| RustDesk ID | 必填。按文本保存，在同一账号的通讯录内唯一。发起连接时使用该 ID。 |
| 别名 | 可选。为空时显示设备 ID。 |
| 标签 | 可选。一个条目可有多个标签，用于筛选常用设备。 |
| 备注 | 可选。记录设备用途等说明。 |

同步内容为上述四项。设备的远控凭据由用户在客户端侧管理。

## 同步与更新规则

- 网页、Mac 和 Windows 读写同一份服务端通讯录。一端保存成功后，其他端在下次拉取时取得最新数据。首次登录且通讯录为空时，用户可以直接添加条目。
- 重复提交同一个设备 ID 时返回现有条目。修改其资料使用编辑操作。
- 对同一条目的并发修改按服务端接受顺序提交。同一字段以最后一次成功提交的值为准。
- 移除条目后，其他端在下次拉取时获得更新后的列表。对已移除条目的编辑返回条目不存在，重新加入时使用添加操作。
- 每次新增、编辑或移除按一次操作提交。写入失败时返回可识别的失败结果，用户可以重试。
- 管理服务重启后，用户可以重新登录并读取之前已保存的通讯录。

## 管理端诊断

管理端显示 API 服务器地址，以及最近的登录、通讯录读取和写入结果。对已到达服务端的请求，记录操作、时间和结果，以便区分凭据错误、会话失效和通讯录请求失败。诊断只展示排查所需的信息。

## 验收

Mac 使用 RustDesk 1.5.3 作为首个兼容基准，Windows 使用现有客户端，并在验收时记录版本。客户端登录与通讯录读写按原生接口联调。 [1.5.3 登录源码](https://github.com/rustdesk/rustdesk/blob/1.5.3/flutter/lib/models/user_model.dart) · [1.5.3 通讯录源码](https://github.com/rustdesk/rustdesk/blob/1.5.3/flutter/lib/models/ab_model.dart)

| 场景 | 通过条件 |
| --- | --- |
| 登录与首个条目 | Mac 和 Windows 用同一账号登录。Mac 添加一台已接入的 Windows 设备后，Windows 客户端拉取到同一个 ID 和别名。错误密码请求被拒绝。 |
| 双向更新 | Windows 修改条目的别名和标签。Mac 拉取后和网页显示一致。网页修改备注后，两台客户端也能拉取到该备注。 |
| 重复添加和移除 | 重复添加一条临时记录后只显示一条。移除后，两端再次拉取时该条目已消失。 |
| 并发与持久化 | 两端先后提交同一字段的修改，刷新后显示最后成功提交的值。重启管理服务并重新登录后，已保存条目仍可读。 |
| 退出与改密 | Mac 退出后无法用已撤销的会话访问通讯录，Windows 仍可使用。改密后各端旧会话失效，用新密码重新登录可以读取通讯录。 |
| 连接已同步设备 | Mac 从个人通讯录点选已同步的 Windows 设备，经过设备授权后可以看到 Windows 桌面。 |
